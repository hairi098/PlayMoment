PLAYMOMENTS — TEMA 2 "SOFT ROMANCE" (v12)

PASANG
1. Ekstrak zip ke ROOT proyek (folder yang ada package.json & app/), timpa semua.
2. Hapus file sisa (kalau ada): app/utils/page-editor-extensions.js
3. npm run dev, buka undangan bertema tema-2.

KONSEP: tema = desain bawaan, user cuma ganti DATA
- Semua isi halaman terhubung ke data undangan yang sudah ada lewat token, mis. {{nama1}}, {{nama2}}, {{quotesText}},
  {{tanggalAkad}}, {{lokasiAkad}}, {{penutupDesc}}. Format cadangan: {{weddingSub|The Wedding Of}} (dipakai kalau datanya kosong).
- Foto terikat ke field data (fotoCouple, fotoBride, fotoGroom). Tombol "Lihat Lokasi" terikat ke mapsAkad / mapsResepsi
  (disembunyikan untuk tamu kalau link-nya kosong). Tombol "Open Invitation" membuka halaman berikutnya.
- Di editor (mode user) user TIDAK bisa tambah teks/foto/dekorasi/tombol, tidak bisa hapus/geser. Yang bisa:
  toggle tampil-sembunyi halaman; klik teks → ubah isi data-nya langsung; klik foto → Ganti Foto dari Media; klik tombol → ubah label/link.
  Teks gabungan beberapa data (mis. "{{nama1}} & {{nama2}}") dikunci dan diubah lewat form Data biasa.
- Foto selalu lewat Media (components/editor/MediaPicker.vue: upload → masuk Media → pilih).

MODE DESAINER (untuk kamu bikin/ubah tema): <PageEditor designer /> di edit-undangan/[slug].vue
  → muncul toolbar, tambah Teks/Foto/Tombol/Dekorasi, panel lengkung, animasi, geser dekorasi. Default (tanpa prop) = mode user.

GAMBAR TEMA
- app/config/soft-romance-assets.js: 2 latar + 15 dekorasi sudah terisi LINK asli (assets.satumomen.com).
  Nanti kalau sudah upload sendiri ke public/themes/soft-romance/ (daftar nama file: _DAFTAR-FILE.txt),
  kosongkan link-nya ("") → otomatis pakai file lokal. Kode lain tidak perlu diubah.
- Posisi/animasi dekorasi: daftar SOFT_DECOR di app/utils/page-defaults.js.

CATATAN
- PAGES_VERSION (page-defaults.js) = 3: editor membangun ulang halaman default SEKALI untuk data lama yang versinya lebih rendah
  (edit manual di data lama hilang). Set 0 untuk mematikan. Tampilan tamu/preview tidak pernah mengubah undangan yang sudah ada,
  hanya mengisi default kalau kosong.
- Nama field data yang dipakai (nama1, nama2, quotesText, quotesSource, brideFull, groomFull, brideOrangTua, groomOrangTua,
  tanggalAkad, waktuAkad, lokasiAkad, alamatAkad, mapsAkad, ...Resepsi, penutupDesc, penutupHormat, penutupAmpersand,
  weddingSub, weddingAmpersand, kepadaYth, openingBtnText, fotoCouple/Bride/Groom) diambil dari form editor kamu.
